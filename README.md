# フットサル作戦ボード

▶ **ひらく:** https://sakusaku117.github.io/futsal-board/

フットサルの戦術を「コマ」として記録し、アニメーションで再生できる作戦ボードです。
作った作戦はリンクにして、LINEなどでチームのメンバーと共有できます。
スマホでの操作を中心に作っています。

## 使い方

1. 駒をドラッグして、最初の並びを作ります(コマ1)
2. 矢印・吹き出し・ブロックを書き込みます
3. 「＋ コマ追加」で次の場面を作ります。矢印を描いた駒は、矢印の先に自動で置かれます
4. 「▶ 再生」で、コマの間をなめらかにつないで再生します。駒は矢印の線に沿って動きます
5. 「共有」で、作戦入りのリンクを送れます。開くと自動で再生が始まります

## 書き込めるもの

- **矢印**:パス(点線)・ドリブル(波線)・動き(実線)・シュート(赤)
  - シュートを選んでボールをタップすると、ゴールまでの矢印を自動で引きます
  - パスの矢印をタップすると、パスコースが「通る(緑)」か「通らない(✖)」かを表示できます
- **吹き出し**:指したい場所をタップして、説明を書き込めます
- **ブロック**:「block」と書いたマークを置けます

## 表示

- 全体コートとハーフコートを切り替えられます
- コートを2本指で広げると拡大、つまむと縮小できます
- 再生中だけ「動き」の矢印を隠すこともできます

## 共有

「共有」を押すと、2種類のリンクを選べます。

- **見るだけ**:受け取った人は再生だけでき、編集はできません
- **編集もできる**:受け取った人が作戦を直して、自分の端末に保存できます

リンクには作戦のデータが含まれています。データはURLの「#」より後ろに入っているため、サーバーには送られません。

## 保存と整理

- 「保存」した作戦は、その端末のブラウザ(localStorage)に保存されます。別の端末とは共有されません
- 「一覧」では、作戦をフォルダに分けて整理できます。「≡」を押したままドラッグすると並べ替えられます
- コマの順番は、コマのボタンを長押ししてから横へドラッグすると入れ替えられます
